# Changelog

## 0.1.0 — Unreleased

- Present an Odia-only source tree, documentation, resources, and release history.

- Expand shared contracts to multiple diagnostics and exact fallback/segment
  expectations, with stable case IDs and full Rust/Python conformance records.
- Add independent numeric/calendar oracles, all 1440 clocks, pairwise and deep
  variation matrices, single mutations, limits, controls and concurrency tests.
- Add reproducible PR property seeds, scheduled four-seed deep runs, bounded
  stress workers and failure artifacts. Fix duplicate grouping commas releasing
  a numeric prefix (`1,,234`), discovered by the independent generator.

- Fix whole-span ownership for duplicate percentage/currency markers, unsupported
  space-grouped money, and malformed unit labels; never expand their fragments.
- Fix globally paired wrappers around spaced quantities and numeric/list comma
  boundaries, preserving exact punctuation and original-byte diagnostics.
- Protect explicit +91/cued phones before numeral parsing, with whole Digits-hint
  support; keep ordinary dotted English names out of electronic recognition.
- Load Python fixtures and vocabulary as UTF-8, with a non-UTF-8 subprocess check.

- Introduce `normalizer-or` / Python `normalizer_or`, with locale `or-IN`.
- Add separate conservative NFC cleanup and Odia speech normalization APIs.
- Support ASCII/Odia digits, Indian/international grouping, lakh/crore words,
  INR, decimal percentages, core units, Gregorian dates, and 24-hour clocks.
- Retain original-byte diagnostics, ambiguity policies, cancellation and limits.
- Keep unsupported structured source atomic; specialized speech readers and
  general Odia morphology remain deferred.
- Add shared Odia and Unicode property tests.
- Alpha linguistic defaults require native-speaker/audio acceptance before production.
